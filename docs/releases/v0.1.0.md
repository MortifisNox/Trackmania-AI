The first public release of Trackmania-AI: an AI that teaches itself to drive
a Trackmania (2020) map from a few of your laps and keeps getting faster for
as long as you let it train, on one Windows gaming laptop (RTX 4050 Laptop
GPU, 6 GB).

> **Offline only.** Train on local maps in Openplanet Developer mode, never
> online and never on leaderboards. Read
> [docs/SAFE_USE.md](https://github.com/MortifisNox/Trackmania-AI/blob/v0.1.0/docs/SAFE_USE.md)
> before your first run.

## One-click start

Two new files sit in the **top folder of the repo**, next to `README.md`:

- **`start_training.bat`**: double-click it to update the code, reinstall the
  game plugins, start the dashboard in its own window, open it in your
  browser and train. If the map has no demo laps yet, it asks you to drive
  them first.
- **`tmai_settings.example.json`**: the template for your settings. The first
  time you double-click `start_training.bat` it copies this to
  **`tmai_settings.json`** and opens it in Notepad. Write your map name,
  whether it has checkpoints and the restart button, save, and double-click
  again. Git ignores `tmai_settings.json`, so updates never overwrite it.

**Already have the repo from before this release?** The `.bat` only appears
after you update once by hand. In PowerShell, in your repo folder:

```powershell
git checkout main
git pull
```

Then `start_training.bat` is in the folder, and from then on it updates
itself. Every setting is explained in
[docs/EVERYDAY_USE.md](https://github.com/MortifisNox/Trackmania-AI/blob/v0.1.0/docs/EVERYDAY_USE.md#one-click).

## What's in it

- **Learning:** SAC with a DroQ critic ensemble, started from your demo laps
  and then learning from its own attempts at about 20 decisions per second.
  It sees four small grayscale frames plus the car's state from an Openplanet
  plugin, and drives through a virtual Xbox controller. Pace is rewarded
  against the median of its own recent laps, with a personal-best bonus, so
  it keeps improving after it beats your demo. Sized to fit 6 GB of VRAM.
- **Dashboard** (`http://127.0.0.1:8080`): live telemetry, lap times,
  checkpoint splits, reward and loss curves, with pause, resume, track reset
  and live changes to learning rate, updates per step, entropy target and
  demo share.
- **Safe stop:** Ctrl+C or the dashboard's **Stop safely** saves a final
  checkpoint without corrupting the replay buffer, writes a run report (best
  laps, split comparisons, total steps, learning curves) and saves the best
  lap as an in-game replay.
- **Resume:** training picks up from the last checkpoint, for as long as you
  want to keep going.
- **Tools:** `tmai doctor` checks the laptop, plus test commands for the
  gamepad, screen capture, telemetry and timing.
